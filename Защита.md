# Как объяснить работы на защите

Голубев Егор Витальевич · 3-ТИД-10 · подгруппа 2

Это конспект по фактически реализованному коду. Перед сдачей стоит самому открыть каждую страницу и повторить описанные действия.

## Практическая 1

«Я сделал небольшую настольную игру. Три фишки можно переносить на клетки. Массив players хранит положение каждой фишки, а spaces — названия и эффекты клеток. Функция render строит поле из этих данных. При переносе меняется положение в массиве, после чего интерфейс обновляется».

- `draggable = true` разрешает перетаскивать элемент.
- В `dragstart` ID фишки записывается в `event.dataTransfer`.
- В `dragover` нужен `event.preventDefault()`: без него браузер не разрешает сброс.
- `drop` читает ID и вызывает `move` для нужной клетки.
- Особая клетка может перенести на две позиции, сообщить о пропуске следующего броска или завершить путешествие. Цепочки эффектов намеренно не запускаются.
- Кубик — `Math.floor(Math.random() * 6) + 1`. Это даёт целое число от 1 до 6.
- Для клавиатуры и телефона предусмотрен способ «выбрать фишку, затем клетку».
- Клетки расположены змейкой: после первой строки движение идёт в обратную сторону. Порядок задаётся CSS, логический номер остаётся в массиве.

Показать: перенос Земли на старт, на третью клетку с бонусом +2, на пятую с пропуском, возврат в экипаж и сброс.

## Практическая 2

«Я заменил ограничения из HTML на проверки JavaScript с регулярными выражениями. У формы стоит novalidate. Для каждого поля есть правило и сообщение об ошибке. Проверка запускается при вводе, потере фокуса и отправке. Форма учебная, серверный аккаунт не создаётся».

- `^` и `$` означают проверку строки целиком.
- `[a-z]` и `[A-Z]` — нижний и верхний регистр латиницы.
- `[а-яё]` и `[А-ЯЁ]` — регистры кириллицы, включая ё.
- `(?=...)` проверяет наличие условия, не «съедая» символы: отдельно контролируются буквы обоих регистров, цифры и спецсимвол.
- Три цифры могут находиться в разных местах строки, а не только подряд.
- У логина и пароля длина от 15 знаков. В пароле латиница запрещена.
- ФИО допускает буквы латиницы/кириллицы и пробелы, но отвергает цифры и знаки.
- Возраст 18–120 выбран для тематики взрослого клуба настольных игр; это правило моей страницы, не универсальное требование преподавателя.
- «Очистить форму» сбрасывает значения и ошибки и возвращает пароль в скрытый режим.

Показать: неверный логин без заглавной буквы, логин с двумя цифрами, пароль с латиницей, затем корректный ввод из README. Не использовать свой настоящий пароль.

## Практическая 3

«Стикер создаётся через createElement, а введённый текст записывается через textContent. Каждый объект знает свою зону и координаты. На доске позиция абсолютная, поэтому стикеры не привязаны к сетке и могут накладываться».

- В `dragstart` запоминается точка захвата стикера.
- При `drop` из положения курсора вычитается положение доски и смещение захвата.
- Координаты ограничиваются размерами доски, чтобы стикер оставался внутри неё.
- `zIndex` поднимает перемещённый стикер поверх остальных.
- Кнопка удаления вызывает `removeSticker` только для своего ID.
- Цвет задаётся при создании стикера и не меняется после его переноса. Перерасчёт положения при изменении окна запускается с небольшой задержкой, когда ширина стабилизировалась.
- `clearZone` очищает одну зону; вторая сохраняется.
- Обработчики кнопок используют `stopPropagation`, чтобы удаление не воспринималось как выбор или перенос стикера.

Показать: создать три стикера, перенести два на доску, положить один поверх другого, вернуть во входящие и очистить только одну зону.

## Практическая 4

«Три поля должны содержать непустой текст после trim. Пока это не выполнено, кнопка отправки отключена. Тема меняет CSS-класс самой открытки. При отправке в localStorage записывается массив открыток».

- `preview` обновляет предпросмотр при вводе и выборе темы.
- Есть пять разных тем, а фон страницы не переключается.
- `JSON.stringify` превращает массив в строку для хранилища; `JSON.parse` восстанавливает массив.
- При открытии страницы `readCards` загружает историю, а `renderHistory` строит открытки.
- `storage` обновляет историю в другой вкладке того же адреса.
- Удаляется только ключ этой работы; `localStorage.clear()` не вызывается.
- Перед удалением всей истории появляется подтверждение; отмена сохраняет открытки.
- «Отправить» означает добавить открытку в локальную коллекцию. Отправки писем или сообщений нет.

Показать: пустые поля, пять тем, сохранение двух открыток, обновление страницы и вторую вкладку.

## Индивидуальный проект вариант 3

«Я разработал трекер чтения книг. Основные данные — массив books. У каждой книги есть название, автор, жанр, страницы, статус, оценка, заметки, цитаты и прогресс. Постоянная библиотека хранится в localStorage, текущая книга и черновики заметок — в sessionStorage».

`readBooks` читает и проверяет данные. `persist` сохраняет массив. `renderList` строит карточки через `createElement`; помощник `node` задаёт текст и классы. `renderDetail` заполняет подробную карточку. `renderStats` рассчитывает статистику.

Фильтрация выполняется через `filter`, сортировка — через `sort`. Для строк используется `localeCompare` с русской локалью. Видимый список отделён от исходного массива, поэтому сортировка не меняет порядок хранения.

Прогресс — `read / pages * 100`. Число прочитанных страниц должно быть целым от нуля до объёма книги. Когда пользователь достигает последней страницы, книга становится прочитанной, а дата завершения записывается в `completedAt`. Именно она используется для количества книг за текущий год.

Суммы страниц и оценок считаются через `reduce`. Средняя оценка — сумма оценок всех книг, делённая на их число. Общий прогресс — сумма прочитанных страниц, делённая на сумму объёмов. `Map` накапливает количество книг по жанрам; диаграмма нарисована CSS-полосами. Для пустой библиотеки отдельно исключено деление на ноль.

Заметка во время ввода сохраняется как черновик в sessionStorage. Кнопка сохранения записывает её в книгу в localStorage. Цитаты хранятся в массиве `quotes` и удаляются по индексу. `textContent` позволяет безопасно показать пользовательские строки с символами HTML как обычный текст.

Показать за 2–3 минуты:

1. Добавить книгу с корректными полями и показать ошибку при нуле страниц.
2. Изменить число прочитанных страниц и показать обновление шкалы и статистики.
3. Переключить фильтры и четыре варианта сортировки.
4. Добавить заметку и цитату, затем удалить только цитату.
5. Набрать черновик заметки, обновить вкладку и показать восстановление.
6. Завершить книгу и показать счётчик книг за год.

## Частые вопросы

**Чем localStorage отличается от sessionStorage?** Первое хранилище сохраняется между сеансами браузера; второе относится к текущей вкладке и переживает её обновление. Оба хранилища относятся к адресу сайта.

**Зачем JSON?** Web Storage хранит строки; для массива объектов нужны сериализация и обратное преобразование.

**Почему не innerHTML для введённого текста?** textContent не интерпретирует ввод как разметку и не запускает вставленный HTML.

**Что произойдёт при недоступном хранилище?** try/catch перехватит ошибку и выведет сообщение. Успешное сохранение в этом случае не объявляется.

**Почему нет базы данных и сервера?** В переданных условиях фронтенд-проекта требуется браузерное хранение. Условия следующих работ по бэкенду пока не переданы.
