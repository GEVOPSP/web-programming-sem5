## Запуск

Откройте `index.html` в браузере. Для одинаковой работы хранилищ и новых вкладок рекомендуется статический HTTP-сервер из корня репозитория:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. На Windows при наличии Python Launcher также можно использовать `py -m http.server 8000`.

## Итоговый проект

Вариант 3 выбран потому, что он единственный не встречается на двух переданных скриншотах выбора вариантов. Полного актуального списка подгруппы нет; новые записи в беседе могут изменить доступность варианта.

Книги хранятся в ключе `gev-web-final3-books-v1` localStorage. Выбранная книга и черновики заметок — в `gev-web-final3-session-v1` sessionStorage. Год завершения определяется при переводе книги в статус «Прочитано». Средняя оценка считается по всем книгам. Данные относятся к этому браузеру и адресу сайта, серверной синхронизации нет.

Отчёт с ФИО, вариантом, двумя скриншотами, объяснением JavaScript и ссылкой на репозиторий: `Отчёт_проект_вариант_3_Голубев.pdf`.
